# 场馆目录与演唱会选择改版结果

日期：2026-10-28

本轮按参考页面完成了场馆目录和演唱会选择器改版。改动只涉及目录呈现、筛选交互和事件选择布局，没有修改座位来源、3D 几何、访问权限或订阅规则。

## 已完成

- 场馆目录现在输出当前目录中的全部 **197 个场馆**。
- 场馆按亚洲、欧洲、北美洲、大洋洲和其他地区分组；每个地区内再按国家/地区分组。
- 支持按场馆名、城市、国家和场馆 ID 搜索；地区按钮显示数量，筛选结果会更新并保留无脚本可读的完整列表。
- 卡片显示城市、Free/Pro 访问状态、分区数量、来源座位数量和打开工具入口。没有来源逐座记录的场馆显示“—”，不虚构座位规模。
- 目录保留已审核场馆的资料链接，未审核场馆仍可从同一张卡片进入工具并由原有权限流程处理。
- 探索页演唱会列表按 `localDate` 分组为日期卡片。每组使用响应式网格，桌面为多列、手机为单列；单个日期超过 6 场时先显示 6 场，并提供“显示更多场次”。
- 场次卡片保留原有名称、日期范围、布局核验状态、官方详情和场次座位图参考链接；点击后仍调用原有布局和座位状态流程。
- 五种语言加入目录筛选、地区、卡片状态和场次展开文案。
