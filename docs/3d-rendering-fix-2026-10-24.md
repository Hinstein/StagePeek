# 3D 几何与选座修正 · 2026-10-24

本轮针对澳门伦敦人剧场看台重叠、座椅向中心汇聚的截图，检查了参考站同馆页面与保留脚本，修正共用导入、几何、渲染、相机和二维分层逻辑。

## 原因与修正

- 参考参数的 a/b 是看台前缘半径，旧版按中线半径解释，减去半层深度后出现错误。新增明确的 `profile-inner-radius` 坐标约定，保留旧版欧美场馆的既有约定。
- 导入丢失 `radialStart/radialEnd`，剧院前、中、后票区落在同一范围。现完整保留径向带、power、oneSided、舞台与 saddle/radial 参数，并重建目录数据。
- 扇形剧院被全圈背景座位和圆环补齐。扇形、单侧及 rear 场馆现保留真实开口。
- 台阶立面曾使用整层高度；现每级只使用一排高度，踏面保持水平，椅背直立。
- 椅子材质错误启用不存在的逐顶点颜色，导致实例颜色失效。现使用白色基础材质与实例颜色，按层与选中状态着色。
- 通用舞台曾按外半径摆放，可能被看台覆盖。没有专属舞台参数的 profile 场馆，现将通用舞台限制在看台前缘以内；仍标注通用示意。
- 总览按座位和舞台包围范围、画布比例构图，排除地面。靠近分区从内场侧观察；靠近/入座不再覆盖完整总览位置。
- 示意场馆的二维分区与三维共用几何；新增池座/楼座层级切换，避免投影叠压。来源平面多边形仍保留其原始屏幕坐标，不作为米制坐标使用。
- 马鞍形看台的踏面高度按各自角度计算，与边缘座椅贴合，避免整排用中央高度造成悬空或下陷。
- 跨层定位、链接直达与点击估算座位均同步二维层级；窗口比例变化后刷新总览取景，观众视角保留当前座位。
- 操作提示随二维、总览与观众视角切换；窄屏工具栏按行排列。
