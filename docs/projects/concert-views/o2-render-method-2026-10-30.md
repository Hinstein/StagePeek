## 实现历史（2026-10-30 起）

日期：2026-10-30。仅限 `twcv-the-o2-arena-london / o2a`，交付仍为“本地研究 v0”。

## 1. 先纠正目标与旧结论

目标是让用户看清分区、排带、舞台方位和大致距离，画面应平顺、连贯。原始数据必须保留，但用户已允许显示位置作示意调整。此前把“来源坐标不能改”扩大成“屏幕上的每把椅子不能移动”，再围着点云补地板，选错了约束。

旧版规范的以下判断撤回：

- **不能用座位数与面片数之比判定质量。** 一块连续面可以承托很多座位；加密面片也不会自动消除断裂。
- **缺座位不等于建筑开口。** 库存缺失、未建模、通道、出入口需要分别判断，不能统一解释成疏散口。
- **逐排串联座位仍不等于连续看台。** 旧 `sourceRowRibbon()` 用距离阈值断开曲面，并按全局高度寻找上一排；它缺少独立的结构边界，也可能把不同楼层接起来。
- **43 排各拟合一个独立椭圆不能保证平顺。** 必须约束相邻排的共同轮廓、排距和转角切线。当前两组 `tiers` 也不能直接当成准确贴合全部座位的几何。
- “10 m”及“±1 m”没有校准依据；这里的原始模型单位不是已证实的米。
- 旧源数据测试通过，只能证明那些数据函数；不能代替当前浏览器实际使用的模型验收。

折线、裂缝和椅子重叠可以由建模及显示坐标管理修复；这不能推出视觉参考已经充分。2026-10-30 补查发现此前缺少安装近景、通道组件和具体分区接口的对照。现已建立[座椅与看台视觉参考板](../research/o2-seating-visual-references-2026-10-30.md)，包含官方 110 区模型、厂商实拍、通道图示和参考站启德 228 区近景。后续以具体结构和固定观察角度检验观感，不再笼统宣称“图片够了”。

## 2. 本轮实现

新增 `public/o2-display.mjs`，生成独立的、标明 `estimated-parametric` 的显示模型。

1. **一套共用轮廓。** 用四段直线与四段相切圆弧组成圆角矩形，43 排沿同一轮廓向外偏移；L1 24 排、L4 19 排。半径、排距、排高参考现有来源数据。直线与圆弧接点共享位置和切线，左右使用同一个结构模型。
2. **先生成完整排面。** 连续踏面、逐排立面独立于每排是否缺椅子。舞台开口使用明确的示意范围，上层与下层之间单独建立平台和立墙，不把层间高差冒充一排台阶。
3. **再放置座椅。** 保留 14,389 个区排座身份及原始 XYZ，另算显示位置 `p`；朝向取排线的向内法线。沿整排统一整理最小间距，解决独立分区贴面后椅子重叠的问题；分区交界留可读的间隙。
4. **统一所有显示消费者。** 3D 座椅、支撑面、分区标签、选中边界、2D 座位与命中区、位置标记、观众相机和画面距离都使用显示模型。保存和票号查询继续使用原始记录。
5. **法线与形状一起修。** 曲线立面使用连续法线，踏面与立面的折角保持清楚；没有靠换颜色掩盖接缝。
6. **精度说明同步。** 页面显示“来源票号已匹配 · 位置为示意”；官方区界和事件描摹默认关闭，打开时注明按原始位置对照。

用户认可座椅样式后，进一步授权补全后侧和两侧下层不齐的示意排座。当前在 L1 的 101–112 区建立连续的分区排带和内部通道，填补缺失的后排、前排及突然缩短的尾排。显示层现在分成两类：1,025 把是没有票号的示意补全，508 把是从 3D Digital Venue 公开端台目录和全景视点整理出的参考前排。两类都没有写入原始来源记录、来源 XYZ 或可售库存；参考前排另标记为 `panorama-camera-estimate`，示意补全继续只有显示排索引。

原来的 14,389 条来源记录继续保留；当前显示总数为 15,922（14,389 来源 + 1,025 示意补全 + 508 参考前排）。通道宽度和分区边缘是绘图约束，不是还原疏散口或实测结构。点击示意补全或参考前排只打开分区/参考预览，不能保存为来源座位；2D 与 3D 行为一致。

参考了用户指定的[视野站点](https://shijiao.xingpaste.com/)的实际座排与近景，并复查仓库保留的参考渲染函数。其可复用的原则是用共同几何驱动排面、座椅与相机；不能简化成“复制一个环”或“多生成面片”。Three.js 的[几何法线说明](https://threejs.org/docs/pages/BufferGeometry.html)和[自定义几何教程](https://threejs.org/manual/pages/custom-buffergeometry.html)用于核对曲面光照：非索引三角形各自计算法线会留下分面，曲线方向需要连续法线，台阶折角则应保留。

本轮对照 FlytiX 与 O2 官方模型后，进一步修正三处：

- **通道整体拟合。** 103–110 的镜像分区共用随排深线性变化的宽度包络；宽侧区保留内部通道，窄转角区保持完整座带。以前每排独立投影会让边界摆动。当前通道相邻段方向变化最大为 0.071°，改前为 36.270°；该指标只检验显示路径的折转，不代表建筑实测精度。
- **层间结构拆开。** 下层末排到上层首排之间不再直接封成一面约 8.7 单位高的墙，改成两道退进的示意廊台、前沿、后墙与隔断。它们标记为 `estimated-architecture`，并不增加来源楼层或可售座位。
- **两档椅子同尺寸。** 显示座面/靠背厚度统一为 0.055 模型单位，简单/圆角几何都有支撑。总览滚轮放大也按投影大小启用圆角细节。原始坐标模式的碰撞边界继续使用原配置；本轮只调整 O2 显示模型。

## 4. 后续验收的停止条件

继续使用四遍法：剪影看两层和舞台关系；密度看椅子分离、排线平顺；结构看转角、交界、支撑与层间关系；构图看总览、分区和观众视角是否清楚。无需像素比对。

本轮额外检查了总览放大时 `chairDetail` 从 `simple` 切到 `rounded`、110 观众横向近景和 2D L1。上层通道和排端随后按第 7 节修正。与参考站的完整度仍有差距，建筑入口、包厢与层间结构仍是简化模型，本轮不声称完成建筑复原。

本轮已处理连续排面、转角切线、贴面、位置同步，以及 103–110 区的后侧示意补全。舞台侧和上层保留现有排座范围；补全形态不能用来声称真实通道、建筑入口或完整售票库存。下一次修改应针对可复现的视觉缺陷，不再以审计目录数、面片数或照片数量作为完成标准。

G1–G3 和三条固定标注继续保留：示意舞台；本地研究 v0 · 数据未发布；来源坐标 · 未校准，不代表实测。研究包状态仍是 `local-research-v0 / not-published / undecided`，没有写入公开目录或发布事件。权利决策后的场馆与事件发布仍分别走 `validateVenueManifest` 和 `validateEventPublication`，二者不互为前置。
