# StagePeek 品牌 Logo

Logo 采用已选 D2「Arena Bowl」：紫色同心看台环抱荧光绿舞台，字标更新为 StagePeek。旧文件保留用于历史设计稿兼容，新页面统一引用 stagepeek-* 文件。

## 文件

- `stagepeek-logo-dark.svg`：深色演唱会主题的完整字标，适用于当前网站和深色背景。
- `stagepeek-logo-light.svg`：浅色背景版本。
- `stagepeek-mark.svg`：纯图标版本，适用于 favicon、移动端图标和社交头像。
- `stagepeek-social.svg` / `stagepeek-social.png`：1200 × 630 的社交分享图。

## 颜色

- 夜场背景：`#0B1118`
- 文字白：`#F3F7F1`
- 荧光舞台绿：`#C9FF51`
- 现场紫：`#B984FF`

## 使用规则

- 完整字标建议高度至少 28px；纯图标建议至少 24px，社交头像建议 64px 以上。
- 深色背景使用 `stagepeek-logo-dark.svg`，浅色背景使用 `stagepeek-logo-light.svg`。
- 保持图标四周至少半个图标宽度的留白，不要拉伸、倾斜或给字标添加阴影。
- 纯图标可以独立使用；在窄屏导航中优先使用纯图标或缩短后的完整字标。
