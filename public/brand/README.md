# SeatPeep 品牌 Logo

Logo 以“观众视野 + 座位排线 + 舞台灯光”为核心：眼睛轮廓代表 Peep，内部弧线代表看台座位，中心荧光点代表舞台和观众正在寻找的位置。

## 文件

- `seatpeep-logo-dark.svg`：深色演唱会主题的完整字标，适用于当前网站和深色背景。
- `seatpeep-logo-light.svg`：浅色背景版本。
- `seatpeep-mark.svg`：纯图标版本，适用于 favicon、移动端图标和社交头像。

## 颜色

- 夜场背景：`#0B1118`
- 文字白：`#F3F7F1`
- 荧光舞台绿：`#C9FF51`
- 现场紫：`#B984FF`

## 使用规则

- 完整字标建议高度至少 28px；纯图标建议至少 24px，社交头像建议 64px 以上。
- 深色背景使用 `seatpeep-logo-dark.svg`，浅色背景使用 `seatpeep-logo-light.svg`。
- 保持图标四周至少半个图标宽度的留白，不要拉伸、倾斜或给字标添加阴影。
- 纯图标可以独立使用；在窄屏导航中优先使用纯图标或缩短后的完整字标。
